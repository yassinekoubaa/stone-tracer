# Does prior training membership help whole-journey correspondence?

Freeze v44's 76 stones, 27 fragments, 0.15 tolerance, boundary checks and answer agreement. Primary outcome: fraction of held-out journeys admitting a complete single-record or multi-record witness. Count unresolved separately. Secondary: best intact-record distance, without using the answer margin for ranking.

Use 12 new paired seeds (144–155). Within each pair randomly partition the 64 examples into two disjoint banks of 24 and 16 test cases; stratify all three sets evenly by true answer. Train two models from the same initialization, switching which bank supplies training examples. Use exactly the same minibatch index sequence in the two models. In each model record the actual optimizer batch and an equally sized, intact forward pass of the other bank at exactly the same pre-update weights. Only optimizer-batch labels drive training. Each bank contains 960 occurrences and has the same example repetition counts by construction. Evaluate both archives against all 16 separate test inputs in the same final model. Both members of a pair see the same 16 test inputs. Report discordant cases and heterogeneity across pairs; quantify uncertainty by resampling whole seed pairs. Do not change the threshold to increase the number of matches.
